Adds the spec 25 decision 5 fan-out seams: every process now runs a read-only events tailer (`src/server/eventsTail.ts`) that polls the `events` table and re-emits rows other processes inserted on the local bus, deduplicating by id against a set of locally emitted ids; the web role runs a per-running-run transcript watcher registry (`src/server/transcriptWatchers.ts`) — one `startTranscriptPush` per run per process, driven by `run.started`/`iteration.started`/`run.finished` on the bus plus a periodic `runs` scan — so live transcripts stream through a web-only process for runs executing in a worker. The stage runner no longer starts its own push (scoping turns still do), `startTranscriptPush` catches up on attach and ignores reads that settle after `stop()`, and `make check-split` now boots two web-only `next start` processes plus a worker and asserts cross-process `card.created` delivery and gapless, duplicate-free transcript pushes from the non-executing web process.

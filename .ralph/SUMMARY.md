Splits Radulf into `web` and `worker` roles selected by `RADULF_ROLES` (default both, so `make dev`/`make start`/the image are unchanged). The boot sequence moves from `src/instrumentation.ts` into `src/server/boot.ts`; a web-only process gets a passive orchestrator that only moves cards, while the worker runs recovery, a timer-driven queue pump, stages, improvement-run drivers, schedules, retention and the SIGTERM drain. A plain Node entry `src/worker.ts` (bundled by esbuild to `dist/worker.mjs`, run by `make worker`) imports nothing from `next`. Migrations now run under an exclusive SQLite lock and the auth secret is created with an exclusive `wx` write and re-read on collision, so several processes can boot one fresh data directory at once. `make check-split` (part of `make check`) boots a web-only `next dev` and a worker-only Node process against a temp data dir and drives a mock-provider card Todo → In Review through the web API.

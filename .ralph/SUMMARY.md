Splits Radulf's boot into `web` and `worker` roles selected by `RADULF_ROLES` (comma-separated, default both, so `make dev`/`make start`/the image are unchanged). The boot sequence moved from `src/instrumentation.ts` into `src/server/boot.ts`; a web-only process only ensures the auth secret and opens the database, gets a passive orchestrator that moves cards but never recovers, pumps, starts a stage, drives an improvement run, or ticks schedules/retention; a worker-only process runs everything else, pumps the queue on a 5 s timer (also re-adopting improvement runs a web process created) and installs the SIGTERM drain, without listening on a port.

`src/worker.ts` is a Next-free entry point bundled by esbuild (`make build-worker` → `dist/worker.mjs`, run by `make worker`). Migrations now run under an exclusive SQLite lock and `ensureAuthSecret` uses an exclusive create with re-read on collision, so several processes can boot one fresh data directory at once. `make check-split` (now part of `make check`) boots a web-only `next dev` and a worker-only bundle against a temp data dir with the mock provider and drives a card from Todo to In Review through the web API, then drains the worker with SIGTERM. Cross-process event fan-out, claims and heartbeats are left for the next spec-25 pieces.

Adds a nullable `runs.control` column (`"cancel"` | `"pause"`, migration 0019) so operator verbs reach a run owned by another process. Cancel and reset still finish the run and move the card at once in the calling process, and now also write `control = 'cancel'`; pause (and pause-epic) write `control = 'pause'`. A worker polls the column every `RADULF_CONTROL_POLL_INTERVAL_MS` (default 1 s) for the runs whose `AbortController` it holds, fires the existing abort on `cancel` and clears the signal; the loop honours `pause` at its iteration boundary and `runLoop`'s `finally` consumes a cancel the poll never saw. `finishRun` is now a compare-and-set on `status = 'running'` and `endActiveRun` honours its result, so a control signal racing a run that ends on its own never yields a second terminal status or `run.finished`. The split-process check gains cross-process cancel and pause/resume tests (the cancel test waits for the first iteration so the poll path is exercised); lifecycle and roles suites gain single-process parity tests. The harness is untouched.
